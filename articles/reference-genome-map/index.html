漫话参考基因组：我们为什么需要一张“人类地图”？

如果把一次基因检测想象成一次“破案”，测序仪给我们的，其实不是一本完整的人类基因组说明书，而是一大堆零散的线索。

这些线索可能是几十个碱基、几百个碱基，或者几万个碱基长的 DNA 片段。它们本身并不会告诉我们：“我来自 7 号染色体的某个位置”“我落在 BRCA1 基因里”“我这里多了一个碱基”“我这里少了一大段”。

要理解这些片段，我们需要一张地图。这张地图，就是参考基因组。

参考基因组是什么？

参考基因组可以理解为一套“标准人类基因组序列”。

当我们拿到一个人的测序数据时，第一步通常是把这些 DNA 片段对齐到参考基因组上。这个过程叫比对。比对完成后，我们才能进一步判断：这个人的某个位置和参考序列相比，是不是发生了变化。

比如参考基因组某个位置是 A，而某个样本在同一位置测到的是 G，那么我们就可以记录为一个 SNV。再比如某一段序列在样本里缺失了，或者多拷贝了，我们就可能进一步分析 CNV 或结构变异。

也就是说，参考基因组提供了一个坐标系统。

没有这个坐标系统，测序数据就像一堆没有页码、没有章节名、没有目录的文字碎片。我们可以看到很多字符，却很难知道它们来自哪里，也很难和数据库、文献、临床报告进行对应。

在基因检测中，我们经常会看到类似这样的描述：

chr7:140753336 A>G

BRCA1 NM_007294.4:c.5266dup

17q12 deletion

这些描述背后，都离不开参考基因组。染色体坐标、基因注释、变异命名、数据库索引、临床解读，都需要先约定一张“地图”。

为什么参考基因组会有不同版本？

地图会更新，参考基因组也会更新。

早期的人类参考基因组并不完美。受限于当时的测序技术和组装方法，很多区域很难拼接完整，尤其是高度重复区域、着丝粒、端粒、大片段重复、复杂结构区域。这些区域就像地图上标着“尚未勘测”的地方。

随着测序技术进步，人类参考基因组不断被修订。错误的地方被纠正，缺失的地方被补充，复杂区域被重新表示，新的人群信息也被逐步纳入。

于是，就出现了我们今天经常听到的几个名字：hg19、hg38、T2T、pangenome。

它们并不是简单的“新旧软件版本”。更准确地说，它们代表了人类理解自身基因组的不同阶段。

hg19 是经典版本，使用时间长，生态成熟。

hg38 是目前更推荐的主流线性参考基因组，序列质量和结构表示相比 hg19 有明显改进。

T2T 试图把过去参考基因组中长期缺失的空白区域补齐，让人类基因组从“基本完成”走向“端粒到端粒”。

pangenome 则进一步改变了参考基因组的思路。过去我们习惯用一条标准序列代表人类，pangenome 希望用更多人的基因组共同构建一套参考体系，让参考基因组更好地反映人群多样性。

hg19：一张用了很久的老地图

很多临床检测、遗传病分析、肿瘤 Panel、全外显子组测序流程，至今仍然能看到 hg19 的身影。

hg19 对应的是 GRCh37 体系。它发布较早，但它的影响非常深。大量历史数据、文献记录、数据库注释、实验室内部流程，都曾经围绕 hg19 建立。

这就是为什么在今天，虽然更新的参考版本已经存在，hg19 仍然没有完全退出舞台。

对于临床检测来说，稳定性非常重要。一个实验室如果长期使用 hg19，它积累的变异数据库、阳性样本验证结果、过滤阈值、报告模板、内部经验，往往都和 hg19 坐标紧密绑定。

从 hg19 切换到新版本，并不是把软件参数改一下那么简单。

同一个变异，在 hg19 和 hg38 上的坐标可能不同。某些区域的序列也可能不同。注释结果、过滤结果、甚至个别变异的判读细节，都可能受到影响。

因此，hg19 像一张用了很多年的老地图。它不够新，也有不少历史局限，但路名大家熟，标注大家熟，很多旧档案也都按这张地图存放。

hg38：更推荐的主流线性参考

hg38 对应 GRCh38，是 hg19 之后的重要升级版本。

相比 hg19，hg38 修正了更多参考序列问题，补充了更多区域，也提供了更完善的 alternate loci 表示方式。对于新的 WGS 流程、非编码区分析、结构变异分析、RNA 分析，以及长期维护的新数据库来说，hg38 更适合作为起点。

不过，hg38 依然属于线性参考基因组。

所谓线性参考，可以简单理解为：它仍然试图用一条主参考路径来表示人类基因组。对大多数常规分析来说，这种方式清晰、稳定、方便，也便于建立统一坐标体系。

但人类群体本身非常多样。不同个体之间并不只是某几个碱基不同，还可能存在大片段插入、缺失、倒位、重复、单倍型差异。对于这些复杂差异，一条线性参考路径有时很难充分表示。

这也是 hg38 的边界。

它比 hg19 更准确、更完整，也更适合作为现代基因组分析的主参考版本。但它仍然没有解决“用一条参考序列代表所有人”的根本问题。

T2T：把地图上的空白补上

过去我们说“人类基因组已经完成”，这句话其实需要加一个注脚。

早期参考基因组覆盖了人类基因组的大部分区域，但并没有完全覆盖所有区域。很多重复性很高、结构特别复杂的地方，很长时间都难以准确组装。

比如着丝粒区域、端粒区域、大片段重复区域、核糖体 DNA 区域，以及一些基因家族密集的复杂区域。这些地方在传统参考基因组里经常是空缺、简化或难以解析的。

T2T 的全称是 Telomere to Telomere，也就是从端粒到端粒。

它的目标非常直观：尽可能把每条染色体从一端到另一端完整拼出来。

这件事之所以到近几年才真正取得突破，离不开长读长测序技术的发展。长读长可以跨过很多过去短读长难以跨越的重复区域，让复杂结构变得更容易拼接。

T2T 的意义非常大。

它让我们第一次更接近看到一个完整的人类基因组，尤其是过去长期被忽略或无法解析的区域。对于研究着丝粒、端粒、复杂重复、结构变异、基因家族演化等问题，T2T 提供了新的基础。

不过，在临床常规应用中，T2T 还没有完全替代 hg38。

原因也很现实。大多数临床数据库、注释系统、检测流程、报告坐标，仍然主要围绕 hg19 或 hg38 建立。T2T 的坐标体系、注释资源、软件生态、临床验证体系，还需要时间成熟。

所以，T2T 更像是把地图上长期模糊的区域照亮了。它让我们知道，过去那张地图并不完整，也告诉我们新的区域里还有很多值得探索的内容。

Pangenome：一张地图不够用了

如果说 T2T 解决的是“这张地图还有空白”的问题，那么 pangenome 关注的是另一个更深层的问题：一张地图能代表所有人吗？

传统参考基因组通常来自少数个体。我们把所有人的测序数据都拿去和这套参考序列比较，这在技术上非常方便，但也会带来偏倚。

如果某个人群中常见的一段序列，在参考基因组中不存在，那么这个人群的测序数据比对时就可能出现困难。如果某些结构变异在参考中没有合适表示，那么相关变异也更容易被漏掉或误判。

这就是所谓的 reference bias。

人类不是只有一种基因组结构。不同人群、不同个体之间，存在大量真实差异。尤其在复杂区域、免疫相关区域、结构变异丰富区域、大片段插入缺失区域，单一线性参考往往显得不够灵活。

pangenome 的思路，是用多个高质量个体基因组共同组成参考体系。

可以把它想象成从“一条标准路线”升级为“一张道路网络”。过去我们只有一条主路，所有人都要往这条主路上靠。现在我们希望在地图里保留多条路径，让不同人的真实基因组都能找到更接近自己的路线。

这对未来的基因组医学非常重要。

它有机会改善复杂变异检测，减少人群偏倚，提高非欧洲人群基因组分析的准确性，也可能帮助我们重新理解很多过去难以解释的区域。

当然，pangenome 离临床常规使用还有不少距离。

因为一旦参考体系从“一条线”变成“一张图”，很多问题都会变复杂：坐标怎么定义？变异怎么命名？数据库怎么索引？报告怎么写？不同实验室之间怎么保持一致？软件和计算资源如何适配？

这些问题都需要时间解决。

但方向已经非常清楚：未来的参考基因组会越来越重视多样性。

参考基因组会影响什么？

很多人会觉得，参考基因组只是生信分析里的一个基础文件。实际工作中，它的影响远比想象中更深。

第一，它影响比对。

同一批测序数据，比对到不同参考基因组，某些区域的比对质量可能不同。尤其是重复区域、同源区域、复杂结构区域，参考序列的差异会影响 reads 落在哪里。

第二，它影响变异检测。

比对结果变了，后续 SNV、Indel、CNV、SV 的识别也可能改变。某些区域在旧参考中难以检测，在新参考中可能更清楚。

第三，它影响注释。

变异坐标不同，注释数据库版本不同，转录本选择不同，都可能影响变异落在哪个基因、哪个外显子、是否改变蛋白、是否命中已知数据库记录。

第四，它影响临床报告。

临床报告必须明确使用的参考版本。因为同一个染色体坐标，如果不说明参考基因组版本，就可能造成误解。

第五，它影响历史数据比较。

如果一个实验室过去的数据是 hg19，新项目使用 hg38，那么跨项目比较时就需要进行坐标转换，也就是 liftover。但 liftover 并不是百分之百无损，复杂区域、重复区域、结构变异区域尤其需要谨慎。

所以，参考基因组不是一个可以随便替换的背景文件。它是整个分析体系的地基。

新版本一定会取代旧版本吗？

从技术发展角度看，参考基因组当然会不断进步。但在真实应用中，新版本不会立刻取代旧版本。这和临床检测尤其相关。一个成熟的临床流程，背后通常包含大量验证工作。参考基因组一旦改变，捕获区域、比对质量、变异检测结果、注释数据库、过滤阈值、历史阳性样本、报告坐标，都需要重新评估。

因此，我们会看到一种长期共存的状态。 hg19 会继续存在于很多历史数据和成熟临床体系中。 hg38 会越来越多地用于新流程、新数据库和更全面的基因组分析。 T2T 会在复杂区域、结构变异和新区域研究中发挥重要作用。 pangenome 会逐步推动参考基因组从单一路径走向多路径时代。 不同版本适合不同场景。真正重要的不是盲目追新，而是清楚自己在什么问题上，为什么选择这一版参考基因组。

小结

参考基因组是基因组分析的地图，也是坐标系统。它决定了测序片段如何比对，变异如何描述，数据库如何匹配，临床报告如何书写。 hg19 是经典老版本，生态成熟，历史数据丰富。 hg38 是更推荐的主流线性参考，适合多数现代分析体系。 T2T 让我们看到了更完整的人类基因组，尤其补充了过去长期缺失的复杂区域。 pangenome 则代表新的方向：用更多人的基因组共同构建参考体系，让“人类参考基因组”更接近真实的人类多样性。

从 hg19 到 hg38，从 T2T 到 pangenome，参考基因组的演化其实是一条很清晰的路线：从能用，到更准；从更准，到更完整；从更完整，到更有代表性。
