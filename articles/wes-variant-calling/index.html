WES系列⑧｜变异检测：如何在你的基因组中找到“不同”？

“测序就像拍了一张基因组的超清照片，而变异检测就是用放大镜去找照片上的每一处细节差异。”

1. 变异检测的意义

在 WES 数据分析中，完成比对（Alignment）后，我们得到了一个包含全部测序读段位置的BAM 文件。但这些比对结果还只是“原始影像”，我们需要从中找出与参考基因组不同的地方——这就是变异检测（Variant Calling）。

变异可能是：

  • 单核苷酸变异（SNV）：单个碱基的替换

  • 小片段插入/缺失（InDel）：几个碱基的增加或缺失

  • 结构变异（Structural Variants, SV）：涉及较大 DNA 片段的变化，如大片段缺失（Deletion）、重复（Duplication）、倒位（Inversion）和易位（Translocation）。SV 通常会影响基因结构，甚至改变调控区域，对疾病发生发展有重要影响。

这些“不同”可能是致病突变、良性多态性，也可能是测序误差。变异检测的目标就是区分它们。

2. Germline 与 Somatic 变异

在不同的研究和临床场景中，我们通常会区分两大类变异：

  • Germline（胚系变异）：存在于生殖细胞（精子或卵子）中，并能遗传给下一代。这类变异在一个人全身的细胞中都存在，通常与遗传性疾病、家族性肿瘤等相关。检测 germline 变异通常需要正常组织或外周血样本。

  • Somatic（体细胞变异）：发生在个体生命过程中，由环境因素（如紫外线、化学物质）或 DNA 复制错误导致，通常只存在于部分细胞中。肿瘤样本中的驱动基因突变大多属于 somatic 变异。检测 somatic 变异通常需要肿瘤样本，并最好配对正常对照以区分背景变异。

区分这两类变异，不仅对临床诊断和治疗有重要意义，也会影响变异检测的策略与工具选择。

3. 基本流程概览

变异检测的通用步骤通常包括：

  1. 预处理：对 BAM 文件进行排序（sort）、标记重复（mark duplicates）、重校准（BQSR）

  2. 候选变异检测：使用专门算法在比对数据中寻找可能的变异位点

  3. 过滤与质控：去除低质量、可能的假阳性结果

  4. 生成 VCF 文件：用标准格式记录所有变异信息

其中“标记重复”与“删除重复”不是同一个动作，不同统计口径也不能直接比较，详见NGS Duplicates的统计口径。

4. 主流算法与工具

4.1 GATK HaplotypeCaller

  • 原理：通过局部重组装（local re-assembly）来提高检测精度

  • 优势：在复杂区域（如 InDel 周围）有更好表现

  • 输出：gVCF 或 VCF 文件，常用于 germline 变异检测

4.2 Mutect2（GATK）

  • 原理：基于贝叶斯模型，优化了肿瘤-正常对照分析

  • 优势：对低频率 somatic 变异敏感，适合肿瘤研究

4.3 SAMtools mpileup + BCFtools

  • 原理：基于测序深度和碱基质量的统计模型

  • 优势：简单、高效，适合快速分析

4.4 FreeBayes

  • 原理：基于贝叶斯模型的多样本变异检测

  • 优势：支持多样本联合分析，适用于群体研究

5. 变异检测中的关键参数

  • 测序深度（DP）：某个位点被测序的次数，过低可能漏检，过高可能是假阳性

  • 比对质量（MAPQ）：read 比对到正确位置的可信度

  • 碱基质量（BQ）：每个碱基测序的置信度

  • 等位基因频率（AF）：变异碱基在所有 reads 中的比例

这些参数直接影响变异检测的灵敏度与特异性。

6. 输出文件：VCF 格式

VCF（Variant Call Format）是变异检测结果的标准格式。每一行描述一个变异，包括但不限于：

  • 染色体与位置

  • 参考碱基与变异碱基

  • 质量分数（QUAL）

  • 过滤状态（FILTER）

  • 附加信息（INFO）

7. 注意事项

  • 不同工具检测结果可能不同，建议交叉验证

  • 测序错误、低复杂度区域、重复序列等容易造成假阳性

  • 对肿瘤样本，应使用肿瘤-正常对照策略以减少背景变异干扰

  • 对家系样本，可利用遗传模式进行额外过滤

  • Germline 和 Somatic 变异的检测工具、阈值、过滤策略往往不同，不能混用

小结

变异检测是 WES 数据分析的核心环节之一，从原始的比对结果中提炼出真正的基因变异信息。高质量的 BAM 文件、合适的算法和合理的过滤标准，缺一不可。
