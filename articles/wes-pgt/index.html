WES系列⑲｜PGT中的 WES

当超声提示胎儿结构异常、或家族里有已知的单基因病时，家属面临一个直球问题：到底是不是遗传原因？是否会重演？ 在常规染色体核型 + 微阵列（CMA） 不能解释时，Trio‑WES（父母+胎儿）有机会把答案进一步“点亮”。在 PGT 场景里，WES 则更多用于前期建库与连锁（单倍型）构建，帮助选择更安全的胚胎。

WES 在产前与 PGT 里分别做什么？

  • 产前诊断：针对超声/心超/MRI 明确结构异常而核型/CMA 阴性的胎儿，Trio‑WES 寻找单基因致病变异（SNV/小 indel），并给出遗传模式与复发风险评估。

  • PGT：

  • PGT‑M（单基因病）：WES/靶向测序用于找到家族致病位点、筛选信息性 SNP、构建家族单倍型（降低 ADO 误判），随后在胚胎活检中判读；

  • PGT‑A/PGT‑SR：分别检测非整倍体、结构重排，不以 WES 为首选，通常用浅测序/定量策略。

产前：为何选择 Trio‑WES

家系信息=放大镜。Trio 设计可以：

  1. 快速识别 de novo 新生突变（重度、孤发发育异常常见）；

  2. 明确遗传方式（常显/常隐/X 连锁），从而估算复发风险；

  3. 过滤背景，缩小候选位点；

  4. 辅助 VUS 判断（与表型/遗传模式是否一致）。 样本：胎儿 DNA 来源于 绒毛取样（CVS）/羊水穿刺；务必做 母体细胞污染（MCC） 评估。父母取外周血。

流程一眼看懂

  1. 超声/影像提示结构异常 → 先做 核型 + CMA；

  2. 若阴性或解释不足 → Trio‑WES；

  3. 实验室生成候选清单 → 只回告与表型高度一致、证据充分的 P/LP；VUS 仅说明，不作为决策依据；

  4. 结合表型一致性 + 遗传方式 → 讨论复发风险、分娩与新生儿管理；必要时靶向 Sanger/功能验证；

  5. 阴性报告 → 解释残余风险，考虑 WGS / RNA‑Seq、随访影像与出生后再评估。

PGT‑M 的关键要点

  • 建库：确定致病位点；挑选位点周围的信息性 SNP，构建家族单倍型；必要时引入祖父母/兄弟姐妹增强分辨率；

  • 活检：多在**囊胚期（D5‑6）**取 5–10 个 TE 细胞；

  • 判读：综合位点与连锁，给出“受累/未受累/不确定”；

  • 风险点：微量 DNA 易 ADO；嵌合可能让 TE 与内细胞团不完全一致；信号冲突时“不确定”优先；

  • 移植后：建议 产前复核（羊水/绒毛）。

价值与边界：诊断增益 + 注意事项

  • 在“影像学明确异常+核型/CMA 阴性”的胎儿中，Trio‑WES 可带来额外诊断率（不同队列差异较大）；

  • 发现可管理的单基因病（代谢/内分泌/免疫缺陷等），可指导新生儿期处理；

  • 重估复发风险：区分偶发与可重复，帮助下一胎策略（自然受孕+产前筛查 vs. IVF+PGT‑M）。

注意事项

  • 时间窗（TAT）：产前决策期有限，需确认加急能力；

  • VUS 更常见：胎儿表型未完全展开，避免过度推断；

  • 取材差异：CVS 受胎盘局灶嵌合影响，必要时以羊水复核；

  • 技术盲区：WES 对 非编码/深内含子/复杂重排/重复序列能力有限；

  • 伦理沟通：是否回告附带发现、成人起病疾病、携带者状态——需充分、前置的 知情同意；

  • 报告措辞：产前回告更保守，尽量避免引导性结论。

关于 NIPT 与“无创 WES”

  • NIPT 基于母体血浆 cfDNA，定位于筛查染色体数目异常（部分平台含微缺失/微重复风险评估）；

  • 以 cfDNA 做“无创 WES”仍在研究阶段，信噪比与解读门槛高，不具备确诊能力；

  • 临床沟通中应清晰区分：NIPT=筛查；WES=确诊性致病位点寻找（在合适指征下）。

团队协作与与家属沟通

临床：补齐影像与 HPO 术语；确认核型/CMA 结果；提前解释 P/LP/VUS/阴性等可能结局与时间表。

实验室：Trio 设计、MCC 评估、严格门限；明确回告范围与模板；设置紧急回告通道。

与家属：

  • 阳性：讲清机制、结局区间、复发风险与围产/新生儿管理；

  • VUS：强调“不用于终止妊娠决策”，给出随访与再解读计划；

  • 阴性：说明残余风险与可选的后续策略。

小结

WES 不是“万金油”，但在影像异常且常规检测阴性时，Trio‑WES 往往是关键一步；在PGT‑M中，WES/靶向测序为连锁与判读提供地基。尊重时间窗口、技术边界与伦理沟通，结论才能真正帮到人。
