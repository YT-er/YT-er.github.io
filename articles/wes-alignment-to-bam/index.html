WES系列⑦｜从 FASTQ 比对到 SAM/BAM

“拿到一堆‘ATCG’就像获得一袋拼图碎片，接下来就是把它们拼回到完整的人类基因组蓝图上。”

1. 为什么需要比对（Alignment）？

测序平台产出的FASTQ文件，记录了上百万到上亿条短序列（reads）。这些reads并不知道自己来自基因组的哪个位置。比对的任务，就是把这些“迷路的短句子”放回到它们在参考基因组中的正确位置。

2. 参考基因组（Reference Genome）

参考基因组就像一本“标准地图”。目前人类研究常用的参考基因组版本包括：

  • GRCh37/hg19：较早版本，很多临床数据库基于它建立

  • GRCh38/hg38：最新版本，纠正了前版本的错误并补充了缺失区域

选择参考基因组要注意版本一致性，否则会导致坐标错位。

3. 比对的核心原理

比对算法的核心是如何在海量参考基因组中快速、准确地找到read最可能的来源位置。常见方法包括基于种子-扩展（seed-and-extend）的策略，以及利用Burrows–Wheeler Transform（BWT）或FM-index进行高效压缩索引，从而在有限内存中实现快速搜索。

由于人类基因组长度约30亿bp，而测序read长度通常为100-150bp，直接穷举匹配几乎不可能。主流算法（如BWA-MEM、Bowtie2）通过 索引（Indexing） 技术，大幅减少搜索空间：

  • 建索引：把参考基因组分成易检索的片段，建立索引表

  • 种子匹配：先匹配一小段（seed）碱基，再向两端延伸

  • 评分体系：根据匹配/错配/缺失情况打分，选择得分最高的位置作为比对结果

4. 比对结果文件：SAM 与 BAM

比对完成后，输出的是 SAM 文件（Sequence Alignment/Map）：

  • 文本格式，可直接查看

  • 包含每条read的位置、比对质量（MAPQ）、CIGAR串（描述匹配/缺失/插入）等信息

为了节省存储和加快读取，SAM文件通常会被压缩成 BAM 格式（Binary Alignment/Map）：

  • 优点：体积小、读取快

  • 缺点：需用专用工具（如samtools）查看

此外，还有 BAI 索引文件，用于快速定位BAM中的特定区域数据。

5. BAM文件的具体格式

BAM文件是二进制格式的比对结果文件，由SAM格式压缩而来。它包含两个主要部分：

  • Header（头部）：描述参考基因组版本、比对软件、比对时间等信息

  • Alignment Section（比对主体部分）：每一行代表一个read的比对信息，包括read名称、比对到的参考序列名、起始位置、MAPQ分数、CIGAR串、比对配对信息、测序序列、质量分数等。

BAM文件的字段顺序与SAM格式一致，只是以二进制形式存储。常见字段有：

  • QNAME：read名称

  • FLAG：比对状态的二进制标记，用一个整数表示，实际上是由多个二进制位（bit）组成，每一位代表一种状态。例如：1 表示该read有配对信息，2 表示配对正确比对，4 表示该read未比对，8 表示配对的read未比对，16 表示read在反向链上，32 表示配对的read在反向链上，256 表示该read不是主要比对（secondary alignment），1024 表示该read是PCR或光学重复

  • RNAME：参考序列名

  • POS：比对起始位置

  • MAPQ：比对质量分数

  • CIGAR：描述匹配、缺失、插入等的字符串

  • RNEXT/PNEXT：配对read的信息

  • TLEN：模板长度

  • SEQ：read的碱基序列

  • QUAL：对应的碱基质量分数

⚠ 注意：FLAG 是多位叠加的，例如值 99 就表示同时有 1 + 2 + 32 + 64 这些状态。

FLAG 1024只说明read已经被标记为duplicate，不等于它已从BAM中删除。标记、删除及重复率口径的区别见NGS Duplicates的统计口径。

6. 常见的比对质量指标

指标 含义 参考标准
比对率（Mapping Rate） 成功比对到参考基因组的reads比例 WES数据常见 > 98%
唯一比对率 只比对到唯一位置的reads比例 越高越好
平均测序深度 每个位点平均被测序的次数 WES常见 > 100×
覆盖度（Coverage） 外显子目标区域被至少一次覆盖的比例 WES常见 > 95%
均一性（Uniformity） 各位点测序深度的一致性 > 80%

7. BAM文件在后续分析中的作用

BAM文件是WES数据分析的“基石”，后续所有变异检测、CNV分析、可视化检查等步骤，都依赖于高质量的BAM文件。如果比对有偏差，会直接影响到下游分析的准确性。

常见用途：

  • 变异检测（SNV/InDel calling）

  • 结构变异分析（SV calling）

  • CNV分析

  • IGV可视化检查（查看变异位点的测序情况）

8. 注意事项

  • 注意PCR重复：重复reads过多会降低有效信息量，可用markdup标记

  • 注意低比对率：可能是样本污染、物种混入或文库构建失败

  • 注意参考基因组版本一致性：分析所用的参考基因组应与下游数据库版本一致

  • 注意比对软件参数：不同参数设置可能显著影响比对结果

小结

比对是WES分析流程的“拼图环节”，BAM文件则是分析的“核心原材料”。只有确保这一步的准确性，后续的变异检测才有坚实的基础。
