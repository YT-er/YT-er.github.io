WES系列㉓｜功能验证：从候选变异到致病性证据

WES 把“怀疑对象”放到了台面上，但从“统计学的相关”走到“生物学的因果” ，常常是一条漫长的路。下面我们把这条路拆成可执行的步骤：先明确要证明什么、再选择合适的模型与实验、最后把证据对齐到临床判读与机制图谱上。

一、先问清楚：要“证实”的到底是什么？

  1. 致病机制假设：这个基因对细胞/组织做了什么？常见机制有 丧失功能（LoF）、获得功能（GoF）、显性负效应（DN）、致剪接异常 等。不同机制决定不同策略。

  2. 证据类型目标：我们期望拿到什么强度的证据——细胞层机制证据、动物层表型证据、还是临床可操作证据（药物反应/通路可药性）？

  3. 疾病背景：神经、肌病、免疫、代谢、心血管……不同系统决定样本与读出指标；选择与致病组织贴近的模型更有说服力。

二、体外模型：从基因到分子/细胞层面的评估指标

1) 过表达/抑制与 CRISPR 编辑

  • 过表达/突变体载体：把野生型与突变体 cDNA 分别导入细胞，比较定位、稳定性、相互作用、下游信号。

  • siRNA/shRNA/CRISPR‑i：模拟 LoF；

  • CRISPR‑KO/CRISPR‑KI：直接在细胞系里敲除/敲入患者的具体突变（更接近真实背景）。

2) 评估指标（readout/assay）怎么选？

  • 蛋白层面：表达量/稳定性（Western/脉冲追踪）、定位（免疫荧光/活细胞成像）、复合体组装（Co‑IP/质谱）；

  • 功能层面：通道电生理、酶活、报告基因、转录活性、信号通路活性指标（例如 MAPK/PI3K）；

  • 剪接与NMD：Minigene 验证异常剪接；NMD 抑制实验 + qPCR/长读长测序；

  • 细胞表型：增殖、迁移、分化、凋亡、线粒体功能等。

3) 选择合适的细胞“背景”

  • 通用细胞系：HEK293、HeLa、U2OS 等，操作简便但生理相关性有限；

  • 近源细胞系/原代细胞：如心肌、神经元、肌管；

  • 患者衍生 iPSC模型：把患者细胞重编程为 iPSC 并分化为目标细胞类型，能“还原”患者背景；

  • 类器官（organoid）：在三维环境中重构组织结构（脑、肝、肠、肾）。

三、动物模型：把“机制”投影到“表型”

1) 模型物种的选择

  • 斑马鱼（Daniorerio）：发育快、透明、便于高通量筛查，适用于形态与发育相关表型（心脑血管、颅颜、肌肉）。

  • 小鼠（Mus musculus）：哺乳动物、遗传工具成熟，适合系统层复杂表型与行为学；

  • 线虫/果蝇：通路保守、周期快，适合初筛与遗传互作图谱；

  • 大动物（猪、非人灵长类）：在心血管、代谢、神经退行等研究中用于关键验证，但成本高。

2) 构建方式与策略

  • KO（敲除）：验证 LoF；

  • KI（敲入）：引入患者特定突变，观察表型与剂量效应；

  • 条件性/组织特异：Cre‑loxP 精准到组织或发育阶段；

  • 转基因：过表达野生型或突变体以模拟 GoF/DN。

3) 评估指标与量化

  • 发育/形态：器官大小、结构、形态计量；

  • 生理功能：心电、代谢、肌力、神经电生理；

  • 行为学：运动、学习记忆、社交谱系行为（ASD 研究常用）；

  • 组织学/分子：免疫组化、原位杂交、单细胞转录组。

四、把证据串起来：整合 ‑OMICS 与可药性

  • WES + RNA‑Seq：确认表达/剪接后果（见前一篇）。

  • 蛋白组/代谢组：把分子改变投射到通路层；

  • 空间转录组/单细胞组学：定位受影响的细胞亚群与微环境；

  • 药理学验证：若推断通路可药（如激酶亢进、离子通道开放概率变化），在细胞/模型动物上用药逆转，形成“因果—可逆”的强证据。

五、质量与对照：让结果“站得住”

  • 对照成套：野生型、突变体、救援（rescue：通过补回 WT 或校正突变，观察表型是否恢复）、阴性/阳性对照；

  • 复现与统计：生物学复现 + 技术复现；盲法/随机化；合适统计学方法（样本量估计、功效分析）；

  • 避免过度外推：细胞系阳性不等于生理相关；动物表型需与人类疾病可映射；

  • 记录可追溯：序列、质粒、细胞/动物背景、实验流程、原始数据共享。

六、把实验证据“落地”到临床分级

  • ACMG/AMP（胚系）与 AMP/ASCO/CAP（肿瘤）：把功能证据映射到 PS3/BS3 等条款（经过良好设计、可重复、与机制一致的实验，才算“强证据”）。

  • 与“疾病机制”一致：例如该基因明确为 LoF 机制致病时，证明突变造成 LoF 更有说服力；若该病多为 GoF，LoF 的证据则不支持致病。

  • 与临床相衔接：把功能结果写进可操作建议：用药敏感性、监测指标、家族管理。

七、三个一口气能记住的范式

  1. 剪接/VUS → Minigene/RNA → iPSC‑分化 → rescue：逐级加码，最后以救援实验定音；

  2. LoF 候选 → CRISPR‑KO/KI 细胞 → 关键功能指标下降 → 小鼠 KI 复现 → 小分子/抗体逆转；

  3. GoF 候选 → 过表达/电生理 → 通道/激酶活性上调 → 抑制剂阻断 → 行为/生理改善。

小结

WES 找到“谁可疑”，功能验证回答“为什么”和“怎么办”。细胞与动物模型不是“形式主义的打卡”，它们是连接临床与机制的桥梁。走完这条路，才能把“候选变异”变成“可信证据”，把“统计关联”变成“因果链条”，并为治疗与管理留下真正可用的抓手。
