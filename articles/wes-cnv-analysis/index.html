WES系列⑫｜拷贝数变异（CNV）分析：WES数据的“隐藏信息”

“除了点突变和小片段 InDel，WES 还藏着大片段基因缺失与扩增的信息。”

1. 什么是 CNV？

拷贝数变异（Copy Number Variation, CNV）指的是基因组中大片段 DNA 的缺失或重复，大小通常在kb 到 Mb 级别。CNV 会导致基因拷贝数异常，进而影响蛋白表达水平。例如：

  • HER2 基因扩增 → 乳腺癌患者可使用曲妥珠单抗（Herceptin）。

  • SMN1 缺失 → 与脊髓性肌萎缩症（SMA）相关。

在临床检测中，CNV 是仅次于 SNV 和 InDel 的另一类重要突变形式。

2. WES 数据如何检测 CNV？

虽然 WES 主要是针对外显子区域的点突变和小片段变异设计的，但通过对**测序深度（read depth）**的分析，同样可以推断出 CNV。其基本原理是：

  • 某个外显子区域的 测序覆盖度显著升高 → 可能存在基因扩增。

  • 某个区域的 测序覆盖度显著降低 → 可能存在基因缺失。

3. 常见的检测方法

WES 数据的 CNV 检测主要有三类方法：

  1. 基于读段深度（Read Depth）

  • 思路：通过比对不同区域的平均覆盖度，判断是否存在显著差异。

  • 工具：ExomeCNV、XHMM、CNVkit。

  1. 基于读段配对（Read Pair）

  • 思路：利用异常的 read pair 间距或方向，推断大片段缺失或插入。

  • 工具：BreakDancer。

  1. 基于拼接与信号综合（Integrated Methods）

  • 思路：综合 read depth、read pair、split read 等多种信号，提高检测准确性。

  • 工具：GATK gCNV、Canvas。

4. 常见工具介绍

  • CNVkit：针对 WES 设计，利用 read depth 与 GC 校正，广泛应用于科研和临床实验室。

  • XHMM (eXome-Hidden Markov Model)：通过 HMM 模型分析外显子覆盖度异常。

  • ExomeDepth：基于贝叶斯框架，将样本与参考对照比较，检测 CNV。

  • GATK gCNV：Broad Institute 提供，能在大规模队列中提高灵敏度。

5. 临床案例

在一位乳腺癌患者的 WES 数据中，检测到ERBB2（HER2）基因扩增：

  • 通过 CNVkit 分析发现，HER2 区域的覆盖度明显高于其他外显子。

  • 结合 IHC 免疫组化和 FISH 验证，最终确诊为 HER2 阳性乳腺癌。

  • 临床上，患者因此可以接受 抗 HER2 靶向治疗，显著改善预后。

6. 注意事项

  1. WES 检测 CNV 的局限性：因捕获设计不均一，检测灵敏度低于全基因组测序（WGS）。

  2. 需要合适的对照：CNV 分析往往需要参考样本，避免因测序深度波动产生假阳性。

  3. 结果需验证：临床报告中，CNV 结果通常需要 FISH、qPCR 或 CMA 验证。

  4. GC 偏好性影响：高 GC 或低 GC 区域容易出现测序深度偏差，需要软件校正。

小结

  • WES 不仅能检测 SNV 和 InDel，还能揭示 CNV 这一“隐藏信息”。

  • CNV 的检测依赖于对 测序覆盖度的深入挖掘。

  • 临床上，CNV 分析常常能直接影响用药选择和疾病诊断。
