全外显子测序（WES）突变检测阳性位点筛选标准

一、引言

全外显子测序（Whole Exome Sequencing, WES）作为一种高效的基因变异检测手段，广泛应用于肿瘤、罕见遗传病、免疫疾病等领域。其聚焦于编码区（exome），可在成本可控的前提下捕获大多数功能相关突变。突变检测完成后，如何从海量变异信息中筛选出具有生物学意义的“阳性位点”，成为下游分析与解读的关键步骤。

本文将系统梳理WES数据中突变检测后的阳性位点筛选标准，结合实际项目经验，提供一套可操作性强的筛选框架。

二、WES突变检测流程简述

  1. 样本准备与建库：提取DNA → 建库 → 外显子捕获。
  2. 测序平台：Illumina NovaSeq/Hiseq等。
  3. 数据处理：
    • 质控（FastQC, Trimmomatic）
    • 比对（BWA-MEM至hg38或hg19）
    • 去重（Picard）
    • 突变检测（GATK HaplotypeCaller / Mutect2）
  4. 变异注释：
    • 工具：ANNOVAR、VEP、SnpEff
    • 数据库：dbSNP、ClinVar、1000G、gnomAD、COSMIC等

三、阳性位点筛选标准

筛选阳性突变位点的目标是：提高可信度、排除测序伪阳性、聚焦可能致病或功能突变。具体标准如下：

1. 测序质量过滤

指标 过滤标准 说明
Mapping Quality (MQ) MQ ≥ 30 去除低质量比对
Depth (DP) DP ≥ 10（体细胞）或≥20（胚系） 保证覆盖度
Variant Quality (QUAL) QUAL ≥ 100 表征变异可信度
Variant Allele Frequency (VAF) 一般 ≥ 5%（体细胞）或 40-60%（杂合胚系） 控制突变丰度下限
Strand Bias (FS, SOR) FS ≤ 60, SOR ≤ 3 剔除有明显方向偏倚的突变

2. 数据库参考与频率过滤

  • 群体频率过滤：

    • gnomAD/ExAC/1000 Genomes 中的频率 < 0.01（1%）
    • 若分析罕见遗传病，通常要求频率 < 0.001（0.1%）

  • 已知致病性数据库：

    • ClinVar：筛选为“Pathogenic”或“Likely pathogenic”变异
    • COSMIC：用于肿瘤相关变异判断

3. 生物学功能注释

仅保留可能导致蛋白质功能改变的变异：

变异类型 是否保留 说明
无义突变（Nonsense） 是 产生提前终止密码子
错义突变（Missense） 是 引起氨基酸改变，需结合功能预测
剪切位点突变 是 可能影响mRNA剪接
框移突变（Frameshift） 是 极可能致病
同义突变（Synonymous） 否 一般不致病，除非已知功能变异

可结合功能预测工具（如 SIFT、PolyPhen-2、CADD）评估missense变异的潜在影响。

4. 体细胞变异特异筛选（针对肿瘤）

  • 过滤良性突变：排除常见SNP（dbSNP中 rs编号 + 高频率）
  • 与正常样本对照（matched normal）：若有对照样本，仅保留tumor-specific变异
  • VAF区间设定：
    • 克隆性突变：VAF > 20%
    • 亚克隆性突变：VAF 5%-20%
  • 去除FFPE伪影：如C>T / G>A富集，结合Mutect2的FilterMutectCalls结果判断

5. 技术重复和验证建议

  • 交叉验证：
    • 不同caller（如Mutect2, VarScan2）结果交集
    • 多平台复核（如Panel验证）
  • 生物学验证：
    • Sanger测序
    • qPCR/ddPCR验证变异丰度
    • RNA-seq验证表达层面影响

四、常见注意事项

  1. 参考基因组版本一致性：注释与比对需一致（hg19 vs hg38）
  2. FFPE样本特异性噪音：注意C>T / G>A伪突变
  3. 批次效应和污染监测：增加多样本QC（如VerifyBamID, ContEst）
  4. 自动化与审阅结合：建议构建标准化Snakemake或Nextflow流程，但重要位点应人工核查（如IGV验证）
