WES全流程

从原始FASTQ数据到最终可临床解读的突变列表，一般包含如下主要步骤：序列质量控制、序列比对、BAM后处理、变异检测、变异注释与过滤、临床解读及结果输出。各步骤常用的工具及其功能列于下表。

工具（类别） 功能描述
FastQC 原始FASTQ质量评估（序列质量分布、GC含量、重复序列等） 。
MultiQC 汇总多样本FastQC报告，提供整体QC概览。
Cutadapt/Trimmomatic 去除测序接头和低质量末端，提高后续比对质量 。
BWA-MEM/Bowtie2 序列比对工具，将过滤后的reads比对到参考基因组（如hg19/hg38） 。
SAMtools BAM文件处理（排序、索引、格式转换等），也可做mpileup调用变异。
Picard MarkDuplicates 标记（或移除）PCR重复reads，避免重复引入偏差 。
GATK BaseRecalibrator 基于已知变异库（dbSNP、1000G等）重校正测序质量分数（BQSR），提高突变检测准确性 。
Qualimap/Picard 对齐后BAM文件质控，计算覆盖度、插入片段大小、测序误差率等指标 。
GATK HaplotypeCaller 常用的SNV/Indel变异检测工具，生成单样本或GVCF格式变异调用结果。
FreeBayes/VarScan2/SAMtools mpileup 其他变异检测工具，可与GATK互补提高敏感性 。
GATK GenotypeGVCFs / CombineGVCFs 多样本联合基因分型（若有亲子或多人样本联调）。
GATK VQSR / VariantFiltration 变异质量重校准或硬过滤，去除低质量假阳性。
ANNOVAR 变异注释工具，可批量查询dbSNP、1000G、dbNSFP、ClinVar等数据库 。
Ensembl VEP 变异效应预测工具，注释基因模型影响，可并入ClinVar、gnomAD等数据。
IGV 图形化查看突变位点的比对情况，用于变异验证和解读。

主要数据库资源： 变异注释和临床解读常用数据库包括：

  • gnomAD/1000G/ExAC：人群等位基因频率库，用于过滤常见多态性；

  • ClinVar：公共临床变异数据库，提供已知变异的致病性注释 ；

  • HGMD：商业致病变异数据库，收录文献报道的病理变异；

  • OMIM：基因-表型关联数据库，用于基因功能和疾病关联检索 ；

  • dbSNP/ClinGen/HPO等：用于变异登记、基因剂量敏感性及表型注释。

此外，还可参考ACMG基因推荐列表、ACMG/AMP变异分类指南等资源指导解读流程。

1. 原始数据质控与预处理

对测序产生的原始FASTQ文件进行质量评估。使用FastQC检测序列质量分数分布、GC含量、接头污染、重复序列比例等 ；使用MultiQC整合多样本QC结果。若发现大量接头序列或低质量末端，可使用Cutadapt或Trimmomatic进行接头切除和低质量序列修剪 。QC常用指标包括：总reads数、Q30碱基比例（通常>80%）、GC含量是否符合预期、序列重复比例等。

QC指标示例： 建议测序深度达到平均约100X （或根据设计目标调整），目标区≥20X覆盖度占比应在95%以上  ，duplication率一般不超过15% 。

2. 比对（Alignment）

将高质量reads比对到参考基因组（一般使用GRCh37或GRCh38主参考基因组，不包含或仅包含主组拼接体）。常用比对工具为BWA-MEM（DNA测序首选） ，也可使用Bowtie2。比对完成后生成SAM/BAM格式文件。利用SAMtools或Picard对BAM文件进行排序、索引；使用Picard MarkDuplicates标记PCR重复reads 。一般外显子测序PCR重复占5–15%左右 。标记重复后，建议再次统计测序覆盖度和覆盖均匀性（如使用Qualimap、Picard CollectHsMetrics等）。

对齐后QC： 对齐后应检查比对率（通常>95%）、插入片段大小分布、一致性覆盖度等。可以利用Qualimap等工具计算覆盖深度、错误率、重复率等统计值 。在家系测序中，还可使用KING或Peddy进行亲子关系验证、样本混淆检测等 。

3. BAM后处理（Base Recalibration等）

参考GATK Best Practices进行后续数据清理。首先使用标记重复的BAM进行基线质量重校准（BQSR）：GATK的BaseRecalibrator根据已知变异位点（如dbSNP）统计并校正测序质量分数 。接下来可选择进行Indel重定位（older GATK版本推荐），减少插入缺失引起的比对错误；新版GATK4中HaplotypeCaller已集成局部重定位，可视需要采用 。上述步骤主要是纠正测序偏差，可在必要时实施以略微提高变异检测准确率 。最后，生成“analysis-ready”BAM文件，用于变异检测。

4. 变异检测（Variant Calling）

使用校正后的BAM调用变异。GATK HaplotypeCaller是目前临床常用的SNV/Indel检测工具，可生成单个样本的VCF或多样本联合调用的VCF（通过CombineGVCFs+GenotypeGVCFs） 。为提高敏感性，临床管线通常推荐结合多种调用器：常见工具还包括SAMtools mpileup/BCFtools, FreeBayes, VarScan2等 。调用时一般只在外显子捕获目标区域或附近（例如扩展±100–200bp）进行，以避免过多低质量的非靶区假阳性 。

过滤条件： 对于小样本（如单个外显子样本），通常采用硬过滤（GATK VariantFiltration）去除低质量变异，例如质量/深度比（QD）、测序深度（DP）、映射质量（MQ）、FisherStrand偏倚（FS）等指标。同时应用频率过滤（见下文）去除常见多态性。对于大批量样本，可采用GATK的**变异质量重校准（VQSR）**方法进行更精细的过滤。

5. 变异注释（Annotation）

将初步变异调用结果（VCF文件）导入注释工具进行功能和临床意义注释。常用注释工具包括ANNOVAR、Ensembl VEP、SnpEff等。这些工具可提供变异基因名、蛋白变化、基因区位置、保守性指标，以及调用相关数据库的信息。例如，ANNOVAR可批量查询dbSNP、1000 Genomes、dbNSFP（含SIFT、PolyPhen、CADD等预测）、COSMIC、ClinVar等 。通过注释可以获得每个变异的等位基因频率、致病性预测以及与已知疾病的关联。注释后，一般输出带有丰富信息的注释VCF或表格列表，列出基因、变异类型、氨基酸影响、频率、致病性等字段。

6. 变异过滤与优先级评估

注释后需对候选变异进行过滤和优先级排序。常用临床过滤标准包括：

  • 人群频率过滤： 去除在常见人群数据库（如gnomAD、1000G）的等位基因频率较高（如>1%）的变异；

  • 功能影响过滤： 优先考虑可能改变蛋白功能的变异（如错义、移码、无义、剪切位点突变），次要关注同义突变等；

  • 致病性注释过滤： 保留ClinVar中已报告为致病或可能致病的变异 ；

  • 基因相关性： 结合患者临床表型，重点关注与疾病相关基因（如使用OMIM、HPO或基因-病症关联数据库）；

  • 继发标准： 根据家系遗传模式（单纯隐性、常染色体显性、X连锁等）筛选合适的基因型；

对于候选突变，最终建立优先级名单并根据ACMG/AMP指南对其致病性进行分类。常用变异优先化和解读工具包括Exomiser、PhenIX、Ingenuity Variant Analysis等，但手动评估也是必要的。

7. 临床解读数据库资源

临床注释常用数据库包括：

  • gnomAD：提供各人群等位基因频率，用于鉴别稀有变异；高频变异一般为良性。

  • ClinVar：公共变异数据库，收录已知变异的临床意义和等级 。

  • HGMD：收集文献报道的致病变异，补充ClinVar未收录的信息。

  • OMIM：检索基因-疾病关联，有助于判断变异是否在已知遗传疾病基因上。

  • 1000G/ESP：历史上重要的基因组资源，可作为频率参考。

  • ClinGen：基因致病证据数据库，提供基因剂量敏感性（haploinsufficiency）等评估。

  • COSMIC：肿瘤体细胞突变数据库（针对肿瘤样本解析）。

利用上述数据库可综合评估变异的病理学和临床相关性。例如，将候选变异与ClinVar记录比对 ，结合gnomAD等频率排除常见多态性，利用OMIM和文献判断基因与表型的相关性等。

8. 分析结果格式与可视化

最终输出形式通常包括带注释的VCF文件和汇总表格（CSV/Excel/PDF）。VCF格式是标准的变异数据输出格式 ，其中包含了每个变异的基因组位置、基因/转录本变体、基因型质量、深度、注释等信息。汇总表格便于人工查看和报告生成，可列出候选变异的详细信息。

在临床工作中，还常用**IGV（Integrative Genomics Viewer）**等可视化工具手动检查关键变异的比对情况（查看突变位点两端的reads支持情况），以排除比对假象和测序错误。可视化的QC图表（如FastQC报告图、覆盖深度分布图、T/Tv比率和病/正常样本变异比较图）也有助于评估样本数据质量和分析效果。

9. 质控标准和注意事项

临床检测对数据质量要求较高，需要设定明确的QC阈值：

  • 测序深度与覆盖度： 建议WES平均测序深度在~100X左右 ；目标区≥20X覆盖度应达到90%以上（某些指南推荐≥95%） ；10X以上覆盖度占比至少90% 。

  • PCR重复率： 应尽量低（一般小于15%–20%） ；过高表明文库过扩增，影响有效覆盖。

  • 比对率： 绝对比例（mapped reads）通常应在95%以上，反映测序与参考一致性。

  • 碱基质量： Q30比例（错误率0.1%）应在80%以上，保证测序可靠性。

  • 异同等位基因频率（VAF）： 对于杂合突变，期望VAF约为50% ；偏离该值可能提示嵌合性突变或假阳性。

  • 样本间关系： 家系测序时应验证性别和亲子关系，一致性异常可能反映样本标记错配或污染。

  • 污染度检测： 利用工具（如VerifyBamID）检查样本DNA污染，通常要求污染率低于3%。

  • 突变统计指标： 常计算全基因组或外显子组的Ti/Tv比值（人源正常样本Ti/Tv约2.8–3.2）作为一项一致性检查。

嵌入全面的质控是保证结果可信度的关键 。如发现异常指标（覆盖度不足、重复率增高、VAF偏离等），需回溯数据流程查找原因（如测序失败或分析参数设置）。建立并定期更新上述质控阈值，以适应测序平台和文库制备的变化，可有效提升临床检测的可靠性。

参考资料： 本流程参考了GATK Best Practices和相关文献，对于工具选择和质控指标等提供指导 。总之，在临床WES分析中，应结合行业指南和本实验室经验，对每一步进行严格验证和质控，确保变异报告的准确可靠。
